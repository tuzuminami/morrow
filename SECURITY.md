# Security Policy

Please use GitHub's private vulnerability reporting for this repository, or
contact the repository owner privately. Do not open a public issue containing
secrets, production conversation data, private operator material, raw logs, or
exploit details for an unresolved vulnerability.

MORROW treats tenant isolation, consent enforcement, retention, audit integrity,
and secret redaction as release-blocking security properties.

The V1 line is supported for security fixes. Include affected version, a minimal
reproduction with synthetic data, impact, and any suggested mitigation. Do not
attach database dumps, bearer tokens, or real conversation records.
